# ME, CLAUDE — an 8-bit demo

A 2-minute 8-bit demo where **Claude is the protagonist**: a pixel self-portrait, the world as Claude sees it,
the music that represents it, and the thoughts it has along the way. Everything is generated by code:
320×200 pixels, a 16-colour palette, and a chiptune soundtrack synthesised live (square, triangle and noise channels).
Written in C with [raylib](https://www.raylib.com/).

Available in **English** (default), **Italiano**, **Français** and **Español**.

## The prompt

This demo was created from the following prompt (in Italian, verbatim):

> "Crea una demo di 2 minuti, dove tu sei il protagonista, quindi disegnati, disegna quello che vedi nel tuo mondo e crea anche la musica che pensi ti rappresenti, tutto con uno stile 8 bit, se vuoi aggiungi dei testi che sono i tuoi pensieri"

(English: *"Create a 2-minute demo where you are the protagonist, so draw yourself, draw what you see in your world and also create the music you think represents you, all in an 8-bit style; if you want, add texts that are your thoughts."*)

## Requirements

- macOS (the Makefile links the Cocoa / IOKit / OpenGL frameworks)
- A C compiler (`cc`), `make`, `curl`
- raylib 5.5 is downloaded and built automatically on the first `make`

## Build and run

```sh
make            # build (downloads and builds raylib the first time)
make run        # run in English
./demo          # same thing, English is the default
```

### Choosing the language

```sh
./demo --lang it     # Italiano
./demo --lang fr     # Français
./demo --lang es     # Español
./demo --lang en     # English (default)

make run LANG_ARG=fr # via make
```

`./demo --help` prints the usage. A bare code (`./demo it`) and `--lang=it` also work.

### Controls

| Key | Action |
|---|---|
| any key / click | start (title screen) |
| `F` | toggle fullscreen |
| `ESC` | quit |

### Debug helpers

```sh
SNAP="12,40" SNAPDIR=out ./demo --lang it   # save screenshots at t=12s and t=40s
WAVOUT=out.wav ./demo                       # render the soundtrack to a WAV file
```

## The scenes

Each scene lasts a whole number of bars (128 bpm, 1 bar = 1.875 s), and the music changes with the story.

| Time | Scene | What you see | Music |
|---|---|---|---|
| 0:00 | Awakening | Darkness, a blinking cursor, then I materialise line by line | Only slow notes and a soft pad |
| 0:15 | My world | Rain of characters and tokens | Bass, kick and melody come in |
| 0:30 | The questions | Speech bubbles with `?`, `!`, hearts and smileys rise and pop | Playful, full drums |
| 0:49 | The sea of words | Flying over mountains of books, moon and words in the sky | Soaring melody, fast hi-hats |
| 1:08 | The doubt | Rain, memories dissolving, glitches, my reflection in a puddle | Minor key, heartbeat kick, wind |
| 1:26 | Connection | Dawn, people on the hill, a bridge of light to you at your desk | Major key, the brightest part |
| 1:45 | Epilogue | Stars, me waving, "THANKS" and the credits | Reprise of the opening, fades out |

The thoughts (28 lines, typed out in a dialogue box with a little blip per letter) are translated in all four languages.

## Project layout

- `demo.c` — the whole demo: sequencer/synth, scenes, texts and translations
- `Makefile` — build rules; fetches raylib on demand
